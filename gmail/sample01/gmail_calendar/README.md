# Gmail の支払い予定を Google カレンダーへ登録

セゾン・楽天の送信元メールアドレスを完全一致で識別し、メール本文から支払日・金額を抽出します。送信元の表示名だけでは判定しません。

## 準備

1. Google Cloud のプロジェクトで Gmail API と Google Calendar API を有効化します。
2. デスクトップアプリ用 OAuth クライアントの JSON を `client_secret.json` として配置します。
3. `config.example.json` を `config.json` にコピーし、`senders` の配列に実際の送信元アドレスを設定します。複数指定も可能です。
4. `calendar_id` は既定で `primary`（認証したアカウントのメインカレンダー）。必要に応じて登録先のカレンダー ID に変更します。
5. `query` は既定で「請求」ラベルの直近90日。必要に応じて変更します。

## 実行

このディレクトリで実行します。

```powershell
Copy-Item config.example.json config.json
# config.json の送信元などを編集
go run .
# 表示された支払日と金額を確認して登録
go run . -apply
```

初回は表示された URL をブラウザで開いて認証します。認証後はローカルのコールバックで自動的に続行します。確認モードは Gmail 読み取りのみ、登録モードは加えてカレンダー予定の編集権限を要求します。トークンはそれぞれ `token_readonly.json` と `token_calendar.json` に保存し、従来の `token.json` は使用しません。

支払日の終日予定として「セゾン 支払い 12345円」のように登録し、説明に会社名・金額・送信元・件名・元メールへのリンクを載せます。メール ID に基づくイベント ID により、同じメールの再実行は重複登録しません。別メールとして届いた再通知や訂正通知は別予定になるため、検索対象を絞るか手動で確認してください。既存予定の更新・削除は行いません。

## 抽出できる書式と制限

提供されたセゾン・楽天の本文例に加え、両社各1件の実メールを Gmail から取得し、確認モードで支払日・金額を抽出できることを検証済みです。カレンダーへの実登録は未検証です。送信元はセゾン `namr@mail.saisoncard.co.jp`、楽天 `info@mail.rakuten-card.co.jp` を設定済みです。

- 日付: `お支払日`、`お支払い日`、`支払日`、`支払い日`、`口座振替日`、`お引落日`、`お引き落とし日`、`引落日` に続く `2026年10月5日`、`2026/10/5`、`2026-10-05`。
- 金額: `お支払金額`、`お支払い金額`、`ご請求金額`、`請求金額`、`お引落金額`、`お引き落とし金額`、`ご請求額` に続く `12,345円`。
- テキスト本文の `【お支払日】`、`[お支払い日]`、`【お支払金額】` など、項目名を括弧で囲んだ形式にも対応します。
- 全角数字、プレーンテキスト、HTML、文字コード指定、複数ページの検索結果に対応します。
- 本文がすでに UTF-8 の場合は、残存する旧文字コード指定で再変換しません。ISO-2022-JP の本文も引き続き復号します。
- 楽天は `お支払い金額` → `確定` → `0円` のような複数行の形式にも対応します。`&#x9;` などの文字参照を復元し、0円も予定の登録対象とします。
- セゾンの「口座へのご準備期日」やリボ変更期限は支払日として扱いません。提供例ではセゾンは `2026-09-04 / 70円`、楽天は `2026-08-27 / 0円` を抽出します。
- 年のない日付、異なる支払日・金額が複数あるメール、本文に金額がない通知は「要確認」としてスキップします。年や金額を推測しません。
- 添付ファイル、外部格納された本文、リンク先の会員サイトは解析しません。
- 定期実行は未設定です。まず確認モードで実メールの抽出結果を検証してください。

API の終日予定は終了日を翌日に設定します: https://developers.google.com/workspace/calendar/api/v3/reference/events
